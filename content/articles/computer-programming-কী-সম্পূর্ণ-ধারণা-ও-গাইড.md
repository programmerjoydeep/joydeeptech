## Computer Programming কী?

Computer Programming হচ্ছে নির্দেশাবলীর কিছু গুচ্ছ যেটি Computer কে দেওয়া হয় নির্দিষ্ট কাজ সম্পূর্ণ করার জন্য।

সহজভাবে বললেঃ

Programming হলো computer-কে কী করতে হবে এবং কীভাবে করতে হবে তা নির্দেশ দেওয়ার পদ্ধতি।

আমরা এই Computer Programming গুলি বিভিন্ন Programming Language এর মাধ্যমে লিখে থাকি এই Programming Language গুলিকেই আমরা High Level Programming Language বলে থাকি। এই High Level Programming Language অনেকটা মানুষের বুঝতে পারা বিভিন্ন ভাষা যেমন বাংলা, হিন্দি, ইংরেজি মতো যা Computer এর বোধগম্য ভাষা Low Level Programming Language এর থেকে তুলনামূলক সহজ।

### Programming Language কী?

**Programming Language** হলো এমন একটি language যার মাধ্যমে programmer computer-কে instructions দেয়। এই Computer Program গুলি বিভিন্ন High Level Programming Language যেমন C, C++, Java, Python ইত্যাদির মাধ্যমে লেখা হয়ে থাকে যেটি নির্দিষ্ট কিছু কাজ সম্পন্ন করতে সাহায্য করে। 

#### জনপ্রিয় কিছু High Level Programming Language এর উদাহরণ

C, C++, Java, Visual Basic, Python, JavaScript, R, Ruby, Kotlin, VB.Net, PHP etc

### Programming কেন শেখা দরকার?

* ### Problem-solving skill

  Programming আমাদের বড় সমস্যাকে ছোট ছোট অংশে ভাগ করে সমাধান করতে শেখায়।
* ### Automation

  বারবার করতে হয় এমন কাজ program দিয়ে automatically করানো যায়।
* ### Website তৈরি

  HTML, CSS এবং JavaScript-এর সঙ্গে programming ব্যবহার করে interactive website তৈরি করা যায়।
* ### Application তৈরি

  Programming ব্যবহার করে mobile ও desktop application তৈরি করা যায়।

### Programming শেখার জন্য কী কী দরকার?

* একটি computer বা laptop
* একটি code editor/IDE (যেমন VS Code, Code Blocks)
* একটি programming language
* Basic computer knowledge
* Logical thinking
* Practice করার মানসিকতা

Beginner হলে **Python বা C Programming Language** দিয়ে শুরু করা যেতে পারে।

> Programming শুধু code লেখা নয়, এটি **logical thinking, problem-solving এবং creativity** উন্নত করতেও সাহায্য করে।
